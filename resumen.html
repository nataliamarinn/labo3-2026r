El Problema

Contexto de la competencia Kaggle

Predicción de ventas — Febrero 2020

Dado el historial de ventas de enero 2017 a diciembre 2019, predecir el volumen de ventas de 780 productos distintos para el mes de febrero 2020 (202002).

Datos de entrada

  • sell-in.txt.gz — ventas históricas
  • product_id_apredecir — 780 SKUs objetivo
  • tb_productos.txt — metadatos de producto
  • tb_stocks.txt — niveles de stock

Desafíos

  • Series con pocas observaciones
  • Estacionalidad anual variable
  • Productos con historial incompleto
  • Necesidad de validar aprendizaje temporal real

Métrica

Evaluación en Kaggle mediante error cuadrático medio (RMSE / score público) sobre las 780 predicciones.

Modelos Naif (Baseline)

Tres reglas simples como punto de comparación mínimo

1️⃣

Último Valor

Persistence

La predicción de febrero 2020 es igual al valor de diciembre 2019. Sin memoria de largo plazo.

2️⃣

Promedio 12 meses

Moving Average

Media de todos los meses de 2019. Suaviza variaciones pero ignora estacionalidad.

3️⃣

Año anterior

Seasonal Naive

Valor de febrero 2019. Captura estacionalidad anual. Fallback a promedio si no hay dato.

Implementaciones múltiples: cada modelo naive se desarrolló en tres tecnologías — Polars (DataFrames modernos en Python), DuckDB (SQL analítico en memoria) y R / data.table — como ejercicio comparativo de herramientas.

Experimento Galactus

¿El modelo realmente aprende estructura temporal?

La idea central: "Empiojado Galactus"

Se toma la serie original y se barajan aleatoriamente los 36 valores. Si AutoARIMA da un score similar con datos barajados y con datos reales → el modelo no está capturando estructura temporal real. Si el score empeora significativamente → el modelo sí aprende patrones de tiempo.

Se mantiene

  • Media global de los 36 meses
  • El conjunto de valores (solo el orden cambia)

Se destruye

  • Tendencia
  • Estacionalidad
  • Promedio de últimos 12 meses
  • Valores año a año
Score mejor con datos reales → modelo aprende
Score similar con datos barajados → modelo no aprende
